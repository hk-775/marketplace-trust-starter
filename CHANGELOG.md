# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-08-31

### Added

- Deterministic profile, content, and coordinated-abuse assessments.
- Explainable risk tiers, counter-signals, policy versions, and limitations.
- Explicit rejection of protected-attribute, biometric, face, attractiveness,
  and appearance inputs.
- SQLite assessments, cases, policy controls, metrics, insights, seed reset,
  and SHA-256 audit chain.
- Enforced human-review workflow with named reviewers and documented outcomes.
- Seeded landing page, operator dashboard, guided demo, and animated
  architecture.
- Explicit static publication mode with a read-only dashboard snapshot and no
  API probing.
- Current logical and target AWS services reference architectures in editable
  draw.io and PNG formats.
- Locked `uv` development, CI, Pages, package, and container workflows.
- Repository, reachable-history, package-content, browser, and live service
  release checks.
- Pinned GitHub Actions, manual protected Pages publication, issue forms, and
  open-source governance documents.
